# authentication-api-main
O projeto demonstra uma aplicação autônoma em Java 17+ e Spring Boot 3 que implementa emissão e validação de tokens OAuth2 com controle de acesso baseado em funções (RBAC). Ele utiliza banco de dados H2 em memória, JWTs assinados via RS256 e inclui uma demonstração em console do fluxo completo de autorização.
